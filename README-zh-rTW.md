# 可變字型測試器 N（Fork）

一款 Android 應用程式，允許你輸入任意文字，檢視並調整其 OpenType 特性；可使用系統字型或任何其他字型。

最新 v4 應用程式已包含完整的 Material 3 UI 與 UX 改進。
